# بحر أوسلي للتسوق

متجر عربي حديث لتسوق المنتجات المختلفة عبر واجهة جذابة ومتجاوبة.

## المميزات
- تصميم عربي كامل مع ألوان أنيقة
- قسم رئيسي للعرض والترويج
- تصنيف المنتجات حسب الفئة
- بحث سريع وترتيب حسب السعر
- سلة تسوق تفاعلية مع إضافة/تعديل الكمية
- تصميم متجاوب للجوال والأجهزة اللوحية

## التشغيل
1. افتح الملف `index.html` مباشرة في المتصفح، أو
2. شغل خادم محلي:

```bash
python3 -m http.server 8000
```

ثم افتح الرابط:

```text
http://localhost:8000
```

## الملفات
- `index.html` — هيكل الصفحة
- `styles.css` — التنسيق والتصميم
- `script.js` — منطق المنتجات والسلة
